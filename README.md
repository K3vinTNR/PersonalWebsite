Deskripsi

Website simple untuk mengenalkan diri secara online. Website ini memiliki tampilan modern serta fitur form contact/email agar pengunjung dapat menghubungi pemilik website dengan mudah.

Informasi profil / perkenalan diri
Form contact untuk mengirim pesan
Integrasi email menggunakan Resend
Responsive design untuk desktop & mobile
Dibangun menggunakan SvelteKit
